# EcoTuneR

**EcoTuneR** is an open-source R-based Shiny visualization tool for comparing food web model-derived trophic levels with Bayesian stable isotope analysis (SIA)-derived trophic levels. It was developed to support the validation of Ecopath with Ecosim (EwE) food web models using stable isotope data, and provides an interactive dashboard for interpreting the degree of agreement between the two approaches.

EcoTuneR was developed by the [Lewis Lab at the Graduate School of Oceanography](https://web.uri.edu/lewis-lab/) and is described in:

> Lewis et al. (*in review*). Bayesian stable isotope analysis as a validation approach for marine food web models: a coastal Louisiana, USA case study. *Ecosphere*.

---

## Overview

EcoTuneR takes a pre-formatted input dataset containing Bayesian SIA-derived trophic level outputs (lower bound, upper bound, and mode of the posterior distribution) alongside EwE food web model trophic levels, and launches an interactive Shiny dashboard with three tabs:

| Tab | Description |
|-----|-------------|
| **Summary** | Pie chart(s) showing the proportion of functional groups whose EwE trophic level falls within, above, or below the 95% credibility interval of the SIA-derived trophic level. Clickable lists of functional groups organized by agreement status. |
| **Details** | Species-level probability density plots showing the Bayesian posterior distribution for each functional group alongside the SIA mode and EwE trophic level as vertical reference lines. Navigate through species using forward/back buttons or a dropdown selector. |
| **Next Steps** | A structured table of interpretive considerations to help researchers understand possible explanations for agreement or disagreement between methods (e.g., detritus-based diets, tissue integration time, temporal mismatches). |

An optional **export** function generates an HTML summary report and saves individual density plots as PNG files for all functional groups.

## Input Data Format

EcoTuneR requires a data frame with **exactly 5 columns in the following order**:

| Column | Name | Description |
|--------|------|-------------|
| 1 | Consumer | Functional group or species name (character) |
| 2 | Lower Bounds | Lower bound of the 95% Bayesian credibility interval for SIA-derived trophic level |
| 3 | Upper Bounds | Upper bound of the 95% Bayesian credibility interval for SIA-derived trophic level |
| 4 | SIA Mode / Trophic Position | Modal value of the Bayesian posterior distribution (the point estimate for SIA-derived trophic level) |
| 5 | Ecopath Trophic Level | Trophic level generated by the EwE food web model (`NA` if not available for a given group) |

Column names in the CSV do not need to match exactly, but **column order is critical**.

These outputs are generated by running the tRophicPosition Bayesian model (Quezada-Romegialli et al., 2018) on your stable isotope dataset and then combining those outputs with EwE model trophic levels into a single data frame.

### Example input structure

```
Consumer,           Lower,  Upper,  SIA_Mode,  EwE_TL
Adult_Red_Drum,     2.81,   3.94,   3.42,      3.10
Juvenile_Red_Drum,  2.54,   3.71,   3.08,      2.90
Brown_Shrimp,       1.95,   2.88,   2.41,      2.20
Oyster,             1.80,   2.60,   2.19,      NA
...
```

A worked example dataset from the coastal Louisiana case study is provided in the [`Example Datasets/`](Example%20Datasets/) folder:

```
Example_combined_output.csv
```

## Usage

### Basic usage (launches Shiny app)

```r
# Source the tool
source('https://raw.githubusercontent.com/LewisLab-URI/EcoTuneR/main/EcoTuneR.R')

# Load your combined output data
combined_output <- read.csv("your_combined_output.csv")

# Launch the dashboard
ecotuneR(combined_output)
```

### Using the example dataset

```r
source('https://raw.githubusercontent.com/LewisLab-URI/EcoTuneR/main/EcoTuneR.R')

combined_output <- read.csv("https://raw.githubusercontent.com/LewisLab-URI/EcoTuneR/main/Example%20Datasets/Example_combined_output.csv")

ecotuneR(combined_output, bypass_check = TRUE)
```

### Function arguments

```r
ecotuneR(combined_output, export = FALSE, bypass_check = FALSE)
```

| Argument | Type | Default | Description |
|----------|------|---------|-------------|
| `combined_output` | data frame | required | Input data frame in the 5-column format described above |
| `export` | logical | `FALSE` | If `TRUE`, exports an HTML summary report and individual PNG density plots to a folder rather than launching the Shiny app |
| `bypass_check` | logical | `FALSE` | If `TRUE`, skips the interactive data format verification dialog. Useful for scripted/automated workflows once your data format is confirmed |

### Export mode

```r
# Export results to a folder instead of launching the app
ecotuneR(combined_output, export = TRUE, bypass_check = TRUE)
```

This will create a folder called `Exported Results of combined_output/` in your working directory containing:
- `A Summary of combined_output.html` — an HTML report with the summary pie chart and color-coded results table (green = within 95% CI, red = outside 95% CI)
- One `.png` density plot per functional group

## Workflow: Preparing inputs with tRophicPosition

EcoTuneR is designed to work downstream of the [tRophicPosition](https://github.com/clquezada/tRophicPosition) package (Quezada-Romegialli et al., 2018). A typical workflow is:

1. **Collect stable isotope data** (δ¹⁵N and δ¹³C) for all functional groups and baselines in your system
2. **Run the Bayesian trophic position model** using tRophicPosition with a dual-baseline model appropriate for your system
3. **Extract the posterior summary** — lower bound (2.5th percentile), upper bound (97.5th percentile), and modal value (`getPosteriorMode()`) for each functional group
4. **Combine with EwE trophic levels** from your Ecopath model output into a 5-column data frame
5. **Run EcoTuneR** to visualize agreement and interpret discrepancies

---

## Interpreting Results

EcoTuneR categorizes each functional group into one of three validation outcomes:

- **Within 95% CI** — The EwE trophic level falls within the Bayesian credibility interval. The two methods are in agreement for this group.
- **Overestimated** — The EwE trophic level falls *above* the upper bound of the credibility interval. The model assigns a higher trophic level than the stable isotope data support.
- **Underestimated** — The EwE trophic level falls *below* the lower bound of the credibility interval. The model assigns a lower trophic level than the stable isotope data support.

The **Next Steps** tab provides structured ecological questions to guide interpretation of discrepancies, including:
- Whether the species relies heavily on detritus (EwE assigns detritus TL = 1, which commonly causes underestimation)
- Tissue type and temporal integration window of the SIA samples
- Temporal alignment between SIA and EwE data collection periods
- Seasonal mismatches in data collection
